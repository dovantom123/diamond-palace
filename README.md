# Diamond Palace Hạ Long
Website giới thiệu trung tâm tiệc cưới và sự kiện, bố cục thích ứng máy tính và điện thoại.

## Mã nguồn
- index.html: nội dung và giao diện.
- assets/depth-motion.js: GSAP và ScrollTrigger.
- assets/: ảnh và font.
- documents/: PDF layout & PCCC gốc.

Website tĩnh, không cần cài đặt thư viện hoặc build. Chạy thử: python -m http.server 8080

## GitHub Pages
Trong Settings → Pages, chọn Source: GitHub Actions. Thiết lập GitHub Pages sau khi chọn phương án xuất bản phù hợp với tài khoản.

Biểu mẫu tư vấn mở ứng dụng email; chưa có máy chủ tiếp nhận yêu cầu. Một số ảnh thiết kế được ghi nhãn minh họa.
